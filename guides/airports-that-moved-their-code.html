Airports that moved their code to a new airport

When Istanbul, Bangkok and Denver opened new airports, the old code went with them. Here's how a city's code can move.

By Amateurgames1 · Published 16 November 2026

Airport codes rarely change. But when a city opens a big new airport to replace its old one, the city's best-known code often moves across too. Passengers keep booking the same three letters, and the old airport either closes or gets a new code.

Istanbul: IST

Istanbul's code belonged to Atatürk Airport for decades. In April 2019 the new Istanbul Airport, north of the city, took over IST in a single overnight move. Atatürk closed to scheduled passenger flights. Istanbul's other airport, on the Asian side, is SAW, Sabiha Gökçen.

Bangkok: BKK and DMK

Bangkok's old airport, Don Mueang, used BKK until Suvarnabhumi opened in 2006 and took the code. Don Mueang closed for a while, then reopened with a new code, DMK, and is now busy with low-cost airlines. Bangkok is one of the few cities where the older airport ended up with the newer code.

Hong Kong: HKG

Kai Tak, with its famous approach between apartment blocks, was HKG. When Chek Lap Kok opened in July 1998, flights moved across overnight and the code went with them.

Denver: DEN

Denver's old airport, Stapleton, was DEN. When Denver International opened in 1995, it took the code and Stapleton closed. The site is now a residential neighbourhood.

Munich and Oslo: MUC and OSL

Munich's new airport opened in 1992, replacing Munich-Riem overnight and keeping MUC. Oslo did the same in 1998: Gardermoen took OSL, and the old airport at Fornebu closed.

Kuala Lumpur: KUL

When Kuala Lumpur International opened in 1998, it took KUL from the older Subang airport, which got a new code and now handles mostly turboprop flights.

And more

  • DOH: Hamad International replaced Doha's old airport in 2014.
  • NGO: Chubu Centrair took Nagoya's code in 2005.
  • ISB: Islamabad's new airport took ISB in 2018.
  • DSS: Dakar's Blaise Diagne airport took DSS in 2017.
  • ATH: Athens's new airport took ATH in 2001 when Ellinikon closed.

When the code doesn't move

Sometimes a city keeps the old airport open and gives the new one a fresh code. Tokyo kept HND when NRT opened, Seoul kept GMP when ICN opened, and Shanghai kept SHA at Hongqiao when PVG opened at Pudong. In those cities you need to know both codes, which is exactly the kind of thing our Quick Play rounds test.

Berlin did something different again. When Berlin Brandenburg opened in 2020 with the code BER, the old Tegel and Schönefeld airports closed, and their codes went out of use.
